## Description
LabWork1. This program rotates an image in bmp format by 90 degrees and applies a Gaussian filter to it.

### Compiler

- **g++** version: `11.4.0`  
- Compilation flag: `-std=c++17`

### Libraries

- Standard C++ libraries, including:
  - `<vector>`
  - `<cstdint>`
  - `<iostream>`
  - `<thread>`
  - `<cmath>`
  - `<fstream>`
  - `<chrono>`
- Unit testing is implemented using **Google Test**:
  - Header: `<gtest/gtest.h>`

make
